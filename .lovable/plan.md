# Ansök-knapp، نسخة CV لكل وظيفة، ومشاركة عامة

## 1. زر Ansök بدل "Alla versioner"
في شاشة نهاية التخصيص (بعد إنشاء السيرة المخصّصة):
- استبدال زر "Alla versioner" بزر رئيسي **Ansök** يفتح رابط التقديم الخاص بالوظيفة في تبويب جديد.
- رابط التقديم موجود أصلًا في بيانات كل وظيفة (حقل الرابط)، سيُستخدم مباشرة.
- عند فتح الرابط تُسجَّل الوظيفة تلقائيًا في التتبّع بحالة "Ansökt" مع تاريخ اليوم، وتُربط بنسخة الـCV المخصّصة.

## 2. زر "Följ den här ansökan"
حاليًا ينقل إلى قائمة الطلبات العامة فقط دون إنشاء طلب — لذلك يبدو بلا وظيفة.
سيصبح: ينشئ (أو يجد) طلبًا لهذه الوظيفة ثم ينتقل إلى صفحة تفاصيل ذلك الطلب مع الجدول الزمني، مع نص أوضح: "حفظ في التتبّع".

## 3. نسخة CV خاصة بكل وظيفة
- تحمل النسخة اسم الوظيفة والشركة (كما الآن) بالإضافة إلى **تاريخ آخر تعديل حقيقي** بدل نص "just now".
- تظهر بطاقة النسخة داخل صفحة تفاصيل الوظيفة وداخل صفحة الطلب: الاسم + تاريخ آخر تعديل + فتح.

## 4. زر مشاركة (Dela)
زر مشاركة على بطاقة النسخة وفي صفحة عرض النسخة، يفتح قائمة بثلاثة خيارات:
- **تنزيل** (PDF عبر طباعة المتصفح إلى ملف)
- **طباعة** (طباعة معاينة الـCV فقط بتنسيق A4 نظيف)
- **نسخ رابط مشاركة** يفتح الـCV لأي شخص بدون تسجيل دخول

## تفاصيل تقنية
- إضافة مسار عام `src/routes/cv.share.$payload.tsx` (خارج `/app`) يعرض `CvPreview` فقط، بدون شريط تطبيق، مع `robots: noindex`.
- محتوى النسخة يُشفَّر داخل الرابط نفسه (base64url لبيانات الـCV + القالب)، فلا حاجة إلى قاعدة بيانات أو تسجيل دخول. إن كان الرابط طويلًا جدًا سنضغط الحقول غير الضرورية قبل الترميز.
- الطباعة/التنزيل عبر قواعد `@media print` في `src/styles.css` تُخفي كل شيء عدا معاينة الـCV.
- ترجمات جديدة (EN/SV/AR) في `src/lib/i18n/ns/tailor.ts` و`cv.ts`: Ansök، Dela، Ladda ner، Skriv ut، Kopiera länk، Senast ändrad.
- تحديث `addTailoredCv`/`updateCvDoc` لتخزين `data` (لقطة محتوى) و`updatedAt` بتاريخ ISO حتى تعمل المشاركة والتاريخ.

ملاحظة: رابط المشاركة يعمل بلا خادم لأنه يحمل البيانات داخله؛ إذا رغبت لاحقًا برابط قصير ثابت وإمكانية إلغائه، نحتاج تفعيل Lovable Cloud.
