# إعادة تصميم أقسام محرر السيرة الذاتية

## الأقسام الست بترتيب ثابت

1. البروفايل (الاسم، المسمى، البريد، الهاتف، الموقع، الروابط، الملخص)
2. الخبرات
3. التعليم
4. المهارات
5. اللغات
6. الريفرنس (المُعرِّفون)

كل قسم يظهر كبطاقة موحّدة الشكل، وفي زاوية البطاقة أيقونة قلم واحدة للتحرير.

## سلوك أيقونة القلم

- الضغط على القلم يفتح نافذة منبثقة (نفس شكل وسلوك نافذة «إضافة خبرة» الحالية: تظهر كورقة سفلية على الموبايل، منتصف الشاشة على الشاشات الكبيرة، إغلاق بالخلفية أو بزر X، حفظ/إلغاء).
- كل نافذة متخصصة بحقول قسمها، وليست نموذجًا عامًا واحدًا.
- النافذة تعرض العناصر الموجودة للقسم قابلة للتعديل، مع زر «إضافة» لعنصر جديد، وزر X بجانب كل عنصر لحذفه.

## حقول كل نافذة

- البروفايل: الاسم، المسمى الوظيفي، البريد، الهاتف، الموقع، الروابط (سطر لكل رابط + X)، الملخص المهني.
- الخبرات: المسمى الوظيفي، رب العمل، الموقع، تاريخ البداية، تاريخ النهاية، المهام (سطر لكل نقطة).
- التعليم: البرنامج/الشهادة، **الجهة المنظمة** (جامعة/مدرسة/معهد)، تاريخ البداية، تاريخ النهاية، ملاحظة.
- المهارات: قائمة نصية، إضافة عنصر + X لكل عنصر.
- اللغات: اللغة + المستوى (مبتدئ/متوسط/جيد جدًا/لغة أم)، إضافة + X.
- الريفرنس: الاسم، المسمى/العلاقة، جهة العمل، البريد، الهاتف، إضافة + X.

## الحذف

كل عنصر قابل للإضافة (خبرة، تعليم، مهارة، لغة، ريفرنس، رابط، نقطة مهمة) يحصل على زر X للحذف مباشرة في النافذة، مع تسمية وصول واضحة.

## ما يبقى كما هو

- المعاينة الحية للقالب، لوحة المساعد والتوصيات، أزرار التحسين/المطابقة، التنقل والشريط السفلي، حساب النسخة (v+1) عند الحفظ.
- الأقسام الأخرى الموجودة حاليًا (المشاريع، الشهادات، التطوع) تبقى تحت بطاقة «أقسام أخرى» ولا تتأثر.
- ترتيب الخبرات بالأسهم يبقى متاحًا.
