# قائمة السير الذاتية بدل القالب في الصفحة الأولى (موبايل)

بعد إدخال السيرة، الصفحة الأولى لا تعرض القالب ولا السيرة بالحجم الكامل. بدلاً منه يظهر تحت قسم القوالب قسم **«سيري الذاتية»**: قائمة بكل السير التي أنشأها المستخدم، وكل بطاقة لها زر **فتح**.

## 1) الصفحة الأولى — قسم «سيري الذاتية»

يظهر فقط عندما توجد سيرة واحدة على الأقل.

```text
[ قسم القوالب ]

سيري الذاتية
┌─────────────────────────────────────┐
│ ● السيرة الرئيسية      [رئيسية]     │
│   محدَّثة قبل ساعتين · 3 نسخ  [فتح] │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│ نسخة — مطوّر واجهات، Spotify        │
│   مشتقة من السيرة الرئيسية · 88%    │
│                              [فتح]  │
└─────────────────────────────────────┘
```

- الضغط على جسم البطاقة = نفس زر «فتح».
- «فتح» ينقل إلى صفحة النسخ الخاصة بهذه السيرة (القسم 2).
- على سطح المكتب: نفس القائمة بعمودين، وباقي الصفحة كما هي.

## 2) صفحة النسخ — شرائط أفقية

عند الفتح تظهر قائمة شرائط أفقية، شريط لكل نسخة:

```text
النسخة الأصلية — مطوّر واجهات    [معاينة] [تحرير] [تكرار] [حذف]
نسخة 1 — Spotify                 [معاينة] [تحرير] [تكرار] [حذف]
```

- **معاينة**: نافذة منبثقة تعرض القالب بمحتوى النسخة للقراءة فقط.
- **تكرار**: ينشئ نسخة بنفس الاسم مع ترقيم يبدأ من «نسخة 1»، ثم «نسخة 2»…
- **حذف**: بعد تأكيد.
- **تحرير**: يفتح النسخة بالكامل (القسم 3).

## 3) صفحة تحرير النسخة

- **القالب A4** بعرض كامل.
- **الشريط السفلي العائم** بأزراره الأربعة الحالية بلا تغيير: تحسين عام، مطابقة مع وظيفة، مهن تناسبك، تغيير القالب.
- **شريط علوي** على يمين العنوان: تحرير يدوي · تكرار · طباعة · تنزيل PDF، وفي الزاوية المقابلة أيقونة سلّة الحذف (بتأكيد).

## اقتراحات إضافية (اختيارية)

1. **شارة الأصل**: كل نسخة مشتقة تعرض «مشتقة من: السيرة الرئيسية».
2. **مقارنة سريعة**: زر يعرض الفروق بين النسخة وأصلها.
3. **حماية الأصل**: منع حذف السيرة الرئيسية طالما لها نسخ إلا بتأكيد صريح.
4. **حالة كل نسخة**: وسم «مستخدمة في تقديم» إذا رُبطت بطلب وظيفة في التتبّع.
