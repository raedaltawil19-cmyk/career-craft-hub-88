# شريط أدوات سفلي عائم لصفحة السيرة (موبايل)

الهدف: بعد إنشاء السيرة يظهر القالب فوراً بكامل الصفحة، والأزرار الأربعة تنتقل إلى شريط عائم أسفل الشاشة فوق شريط التنقّل.

## الشكل

- شريط أفقي واحد بحواف دائرية كبيرة، خلفية شبه شفافة مع blur وظل خفيف، ثابت أسفل الشاشة فوق شريط التنقّل مباشرة.
- مقسوم أربعة أعمدة متساوية، كل عمود: أيقونة صغيرة ملوّنة + سطرين نص قصير:
  1. تحسين عام — أيقونة Sparkles (مرجاني)
  2. مطابقة مع وظيفة — أيقونة Target (بنفسجي)
  3. مهن تناسبك — أيقونة Compass (أخضر)
  4. تغيير القالب — أيقونة LayoutTemplate (أزرق)
- ارتفاع منخفض (~64px)، النص بحجم صغير جداً مع سطرين مسموحين وبدون قصّ.
- الزر النشط (نافذة مفتوحة) يأخذ خلفية soft بلون أيقونته.
- الشريط يظهر على الموبايل فقط (`lg:hidden`)؛ سطح المكتب بدون تغيير.

## السلوك

- شبكة الأزرار 2×2 الحالية فوق القالب تُحذف، فيصبح القالب أول ما يراه المستخدم.
- إضافة مسافة سفلية للصفحة حتى لا يغطي الشريط نهاية القالب.
- عند فتح أي نافذة (تحسين/مطابقة/قوالب) يبقى الشريط ظاهراً كما هو.
- لوحة «مهن تناسبك» تُفتح/تُغلق كما هي حالياً وتظهر فوق القالب.

## تفاصيل تقنية

- `src/routes/app.cv.index.tsx`: إزالة شبكة `ActionTile` 2×2، وإضافة مكوّن شريط سفلي `fixed bottom-[calc(...)] inset-x-0 z-40 lg:hidden` بأربعة أزرار مرتبطة بنفس الحالات الموجودة (`setOpenWindow`, `setShowCareers`, `setPreviewTpl`)، مع `pb` إضافي على حاوية الصفحة.
- `src/lib/i18n/ns/ws.ts`: إضافة أربع مفاتيح نصوص قصيرة للشريط (تحسين عام / مطابقة مع وظيفة / مهن تناسبك / تغيير القالب) بالعربية والإنجليزية والسويدية.
- بدون أي تغيير في المنطق أو البيانات؛ عمل واجهي فقط.
