# Career Navigator Hub

Design a premium, modern, mobile-first web application called:

SMART CV

Smart CV is a Smart Career Workspace, not simply a CV builder.

The product helps a person build, improve, tailor, manage and use their CVs throughout their job-search journey.

IMPORTANT:

Do not copy the visual design of the existing application.

The existing interface is only a reference for some existing product concepts and workflows.

You are responsible for creating a completely new, modern, professional UX/UI.

The application must feel like a serious modern career product, not like a traditional CV template website.

==================================================

1. CORE PRODUCT IDEA

==================================================

Smart CV should help the user move through this journey:

Create/import CV

→ Build a Master CV

→ Improve the CV

→ Discover suitable jobs

→ Analyze a specific job

→ Tailor the CV for that job

→ Review AI recommendations

→ Create a job-specific CV

→ Track the application

→ Continue managing the job-search process.

The Master CV is the user's central career profile.

A Master CV contains the user's complete professional information.

Job-specific CVs are derived from the Master CV rather than becoming disconnected documents.

The product should therefore feel like a Career Workspace rather than a document editor.

==================================================

2. MOBILE-FIRST REQUIREMENT

==================================================

Design the product primarily as a mobile web application.

Mobile is the PRIMARY design target.

The interface must work beautifully across:

- small smartphones

- standard smartphones

- large smartphones

- tablets

- laptops

- desktop monitors

Do not simply shrink a desktop UI onto mobile.

Design the mobile experience first and then intelligently expand it for larger screens.

The desktop version should take advantage of larger screens while preserving the same mental model and workflows.

The application must be responsive and usable with touch.

Use accessible touch targets.

Avoid tiny controls.

Do not overload mobile screens.

==================================================

3. MAIN MOBILE NAVIGATION

==================================================

The mobile application should have a persistent bottom navigation bar.

Use a maximum of four primary navigation areas plus one central action.

The most important requirement:

THE "+" BUTTON MUST BE IN THE CENTER.

The central "+" button is the primary action for adding a new CV.

Example conceptual navigation:

Home

Jobs

+

Applications

Profile

The exact visual arrangement, icons and labels should be designed professionally.

The "+" button should visually stand out while still belonging naturally to the navigation system.

Do not hide the "+" inside a menu.

It must be immediately discoverable.

==================================================

4. THE CENTRAL "+" ACTION

==================================================

When the user taps the central "+" button, open a clean mobile bottom sheet or modal.

Title:

"Add a CV"

Present exactly four primary options:

1. Paste text

2. Upload file

3. Import from LinkedIn

4. Manual form

These four options should be visually distinct and easy to understand.

Use appropriate icons and short descriptions.

Do not make this screen complicated.

==================================================

5. OPTION 1 — PASTE TEXT

==================================================

The user can paste the content of an existing CV.

Workflow:

Tap "Paste text"

→ large text area

→ paste CV

→ Continue

→ AI extracts the information

→ show extracted information for review

→ user confirms

→ create/update Master CV.

The user must be able to review and correct extracted information before it becomes the Master CV.

==================================================

6. OPTION 2 — UPLOAD FILE

==================================================

Allow the user to upload a CV file.

Support common CV formats where technically possible, especially:

PDF

DOC/DOCX

Workflow:

Upload file

→ processing state

→ AI/document parser extracts information

→ show extracted information

→ user reviews

→ user confirms

→ create Master CV.

The UI must clearly communicate processing status.

If extraction fails, provide a friendly recovery path.

==================================================

7. OPTION 3 — LINKEDIN IMPORT

==================================================

Create a dedicated LinkedIn import workflow.

Do not invent functionality that requires unauthorized access.

Design the experience conceptually so the user can import or provide their LinkedIn information through a supported method.

The workflow should be:

LinkedIn import

→ authentication/instructions if required

→ retrieve/import available professional information

→ AI organizes the information

→ user reviews

→ confirm

→ create Master CV.

The user must always remain in control of what gets imported.

==================================================

8. OPTION 4 — MANUAL FORM

==================================================

This is an important workflow.

The user can create a CV manually through a guided form.

Do NOT make this a giant traditional form.

Turn it into a guided conversational/step-based experience.

Ask questions such as:

Personal information

- Name

- Contact information

- Location

- Professional title

Work experience

- Where did you work?

- What was the company?

- What was your role?

- What profession/title did you have?

- When did you start?

- When did you finish?

- What were your main responsibilities?

- What achievements did you have?

Education

- Where did you study?

- What did you study?

- When?

Skills

- What are your main skills?

- Languages

- Tools/software

- Certifications

Other relevant information

- Projects

- Volunteer work

- Courses

- Additional experience

The form should feel intelligent.

After each section, allow the user to review what was entered.

The AI may help improve wording, but must not invent facts.

==================================================

9. MASTER CV

==================================================

After importing or creating the CV, the user arrives at their Master CV.

The Master CV is the central source of truth.

It should contain all professional information.

The user should be able to:

- edit information

- add sections

- remove sections

- reorder sections

- improve wording

- create versions

- choose a visual template

- preview the CV

- export PDF

- print

- use it as the source for tailoring to jobs.

The Master CV should not feel like a simple Word document.

It should feel like structured career data presented through a CV interface.

==================================================

10. CV BUILDER

==================================================

Create a powerful but simple CV workspace.

The user should be able to see:

- CV preview

- editable sections

- AI suggestions

- template controls

- CV quality indicators

- ATS/readability feedback

- save state

- version information.

Do not overload the screen.

On mobile, use appropriate tabs, sheets or collapsible panels.

On desktop, take advantage of the larger screen to show the CV preview and tools simultaneously.

==================================================

11. AI IMPROVEMENT

==================================================

Smart CV should have an AI career assistant.

The AI should analyze the user's CV and suggest improvements.

Examples:

- unclear professional summary

- weak achievement statements

- missing measurable results

- unclear dates

- repetitive wording

- missing relevant skills

- weak structure

- readability problems

- ATS issues.

Suggestions should appear as recommendations.

The user should be able to:

Accept

Reject

Edit

Accept all

AI must not silently change important CV information.

The user remains in control.

==================================================

12. JOB DISCOVERY

==================================================

Create a Jobs workspace.

The system can recommend jobs based on the user's Master CV.

Each job card should clearly show:

- job title

- company

- location

- remote/hybrid/on-site

- match score

- key matching skills

- potential gaps

- date/source where appropriate.

The match score must be presented as an aid, not as an absolute truth.

The user can open a job for deeper analysis.

==================================================

13. SPECIFIC JOB ANALYSIS

==================================================

The user should be able to provide a specific job posting.

Possible input methods:

- paste job description

- upload job description

- provide a supported job URL.

AI analyzes:

- responsibilities

- required skills

- preferred skills

- experience requirements

- keywords

- employer expectations

- potential CV gaps.

Present the analysis clearly.

==================================================

14. JOB MATCHING

==================================================

Compare the user's Master CV against the selected job.

Show:

Strong matches

Potential matches

Missing requirements

Transferable skills

Potential weaknesses

Recommended changes.

Do not fabricate qualifications.

==================================================

15. TAILORED CV

==================================================

The user can create a tailored CV for a specific job.

Workflow:

Select job

→ Analyze job

→ Compare with Master CV

→ AI proposes changes

→ User reviews changes

→ Approve

→ Generate Tailored CV.

The Tailored CV must remain connected to:

Master CV

+

Job

Do not create an isolated document with no relationship to the source.

==================================================

16. APPLICATION TRACKING

==================================================

Smart CV should eventually include job application tracking.

The user should be able to record:

- company

- position

- job link

- application date

- CV used

- status

- notes

- interview

- follow-up

- outcome.

Possible statuses:

Saved

Applied

Interview

Second interview

Offer

Rejected

Withdrawn

Closed

The user should be able to see their application history.

This feature should be designed as part of the Career Workspace, not as an unrelated CRM.

==================================================

17. CAREER WORKSPACE / HOME

==================================================

The Home screen should give the user a useful overview.

Possible areas:

Master CV status

Recent CVs

Recommended jobs

Applications requiring attention

Recent AI recommendations

Upcoming interviews/follow-ups

Career progress.

Do not fill the dashboard with meaningless statistics.

Every element should lead to an actionable workflow.

==================================================

18. PROFILE / ACCOUNT

==================================================

Profile should include:

Personal information

Career information

Preferences

Languages

Account settings

Notifications

Security

Help/support

Logout.

Keep account management separate from career workflows.

==================================================

19. AI AGENT ARCHITECTURE — UX

==================================================

The AI should feel like an intelligent career assistant, not a generic chatbot.

The assistant should understand the current context.

For example:

If the user is editing their CV:

→ AI talks about the CV.

If the user is analyzing a job:

→ AI talks about that job.

If the user is tailoring a CV:

→ AI understands both the job and the Master CV.

If the user is tracking an application:

→ AI understands the application context.

The UI should provide contextual AI actions rather than forcing the user to open a generic chat every time.

Examples:

"Improve this section"

"Make this achievement stronger"

"Compare with this job"

"Find missing keywords"

"Tailor my CV"

"Explain this recommendation"

==================================================

20. AI SAFETY / CONTROL

==================================================

Separate:

READ-ONLY AI

from:

WRITE/EXECUTION AI.

AI may analyze and recommend freely.

Actions that modify important user information should require user confirmation.

Never invent:

- jobs

- qualifications

- achievements

- employers

- dates

- skills

- education.

AI can improve wording but must preserve factual accuracy.

==================================================

21. DESIGN DIRECTION

==================================================

Create a premium, modern career-product aesthetic.

Avoid:

- generic SaaS dashboards

- excessive cards

- excessive gradients

- childish illustrations

- unnecessary animations

- crowded screens

- generic AI-chat interfaces

- traditional boring CV-builder layouts.

The design should communicate:

professional

intelligent

calm

trustworthy

modern

career-focused.

Prioritize:

clear hierarchy

excellent typography

strong spacing

beautiful CV preview

intuitive navigation

high readability

subtle visual feedback.

Create a distinctive visual identity rather than copying LinkedIn, Canva or another existing product.

==================================================

22. MOBILE UX

==================================================

Mobile is the primary experience.

Pay special attention to:

- bottom navigation

- central "+" action

- bottom sheets

- swipe-friendly workflows

- large touch targets

- readable CV editing

- keyboard behavior

- scrolling

- fixed actions where appropriate

- avoiding horizontal scrolling

- safe areas around mobile navigation.

The CV preview must remain usable on small screens.

==================================================

23. DESKTOP UX

==================================================

On desktop, expand the workspace intelligently.

For example, a CV editing screen may use:

navigation

+

main CV canvas

+

contextual AI/tools panel.

But do not simply copy the mobile layout onto desktop.

Use the additional screen space to improve productivity.

==================================================

24. RESPONSIVENESS

==================================================

The application must be genuinely responsive.

Design for:

320px+

small mobile

large mobile

tablet

laptop

desktop

large desktop.

Do not create separate unrelated designs.

Maintain one coherent design system.

==================================================

25. ACCESSIBILITY

==================================================

Design with accessibility in mind:

- readable contrast

- keyboard navigation

- semantic controls

- visible focus states

- accessible labels

- adequate touch target sizes

- scalable typography.

==================================================

26. SEARCH / DISCOVERABILITY

==================================================

This is a web application.

Design the application so that public/marketing surfaces can be SEO-friendly.

The authenticated workspace itself does not need to behave like a public SEO website.

Separate:

Public marketing pages

from

Authenticated application workspace.

==================================================

27. IMPORTANT PRODUCT PRINCIPLE

==================================================

Smart CV is NOT:

"Upload CV → get another CV."

It is:

"Build your career profile → improve it → discover opportunities → understand opportunities → tailor your application → track applications → continue improving."

The Master CV is the central career asset.

Jobs and applications connect to it.

AI operates across this workspace with context.

==================================================

28. DO NOT DO THIS

==================================================

Do not simply reproduce the old Smart CV UI.

Do not copy the existing HTML design.

Do not create a generic dashboard.

Do not invent unsupported LinkedIn functionality.

Do not allow AI to invent user facts.

Do not make the application desktop-first.

Do not hide the central "+" action.

Do not make the "+" button secondary.

Do not turn the product into a generic chatbot.

==================================================

29. FINAL DESIGN OUTPUT

==================================================

Create a complete high-fidelity web application concept covering at minimum:

1. Landing / entry experience

2. Home / Career Workspace

3. Add CV bottom sheet

4. Paste text flow

5. Upload CV flow

6. LinkedIn import flow

7. Manual guided form

8. Master CV

9. CV editor

10. AI improvement panel

11. Jobs workspace

12. Job details

13. Job analysis

14. CV-job matching

15. Tailored CV workflow

16. Applications workspace

17. Application details

18. Profile/account

19. Notifications

20. Empty states

21. Loading states

22. Error states

23. Mobile navigation

24. Desktop responsive layout.

Do not ask me to position every button manually.

Use professional UX judgment to determine the best placement of controls.

However, the following requirement is NON-NEGOTIABLE:

THE "+" ADD-CV ACTION MUST BE THE CENTRAL ACTION OF THE MOBILE BOTTOM NAVIGATION.

When the "+" is tapped, the four options must be:

1. Paste text

2. Upload file

3. Import from LinkedIn

4. Manual form

Build the entire UX around the career workflow described above.

The final result should look like a serious, polished, production-grade career platform rather than an AI-generated generic dashboard.
